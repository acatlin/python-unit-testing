Unit Testing in Python

How to write down what your Python functions should do, as code the computer can check, using the pytest package. For data science students who can write a function and a pandas groupby() and have never written a test.

Each lesson takes 20 to 30 minutes, teaches one skill, and ends with a short quiz. You write every test by hand. The examples are the small data-cleaning helpers you already write: rescaling a column, tidying column names, parsing money, summarising by group.

Lessons

  1. 1 Your first assertion Turn a glance at the console into an assert statement. Tell a pass from a failure.
  2. 2 Test functions and test files Name your tests, give them a folder, and run them all with one command.
  3. 3 Choosing the right assertion The dozen forms you need, and how to test a function that returns a data frame.
  4. 4 Edge cases, errors and bugs Missing values, constant columns, wrong types. Catch a real bug with a failing test, then fix it.
  5. 5 From project to package Move your functions and tests into an installable package and run them with pytest.

Before you start

  • Python 3.11 or later, with an editor that has a terminal: VS Code, Positron, PyCharm or JupyterLab.
  • These packages, installed from a terminal: python -m pip install pytest pandas. Lesson 5 needs nothing more; it shows you how to make a virtual environment.
  • Or install nothing: each lesson has a notebook that runs in your browser with Google Colab (you need a Google account). Open the one for Lesson 1, 2, 3, 4 or 5, or use the link at the top of each lesson.
  • You should be comfortable writing a function and using groupby() on a pandas data frame. No testing experience is assumed.

How to use these pages

  • Type, don't just read. Each lesson has a “Try it” section. The skill is in your fingers, not on the page.
  • Take the quizzes from memory. Lessons 2 to 5 open with two questions about the lesson before. They are meant to be a little hard; recalling something is what makes it last.
  • Come back. One lesson a day works better than five in a row. Retake a quiz a few days later; the answers are reshuffled each time.
  • Ask. When something is unclear, take the exact code and message to your instructor, a classmate, or an AI assistant.
